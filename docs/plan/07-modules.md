> **Mixed.** The folder tree and import rules still apply. Each workstream below is tagged.

The folder tree is the org chart. Each workstream owns a folder and builds against fixtures, so nobody waits on anyone else.

## Import rules

- `ui/` imports only tokens and other `ui/`.
- `domain/` imports `ui/`, `lib/` and core types.
- `features/` compose domain and ui. Features never import each other.
- Client components import core types and schemas and `@casework/tracks/meta` only. Agent code stays in `server/` and route handlers, and every server file starts with `import 'server-only'`.
- `core` never imports a track. Tracks import `core`.
- Import from a folder's `index.ts`, never a deep file.
